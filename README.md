# 🛍️ Customer Shopping Behavior Analytics

A data analytics project exploring customer shopping behaviour using SQL, a CSV dataset, a Jupyter notebook, and a Power BI dashboard file.

## 🎯 Business Questions

The SQL analysis explores questions such as:

- How does revenue compare across customer genders?
- What is the spending pattern of customers who use discounts?
- Which products have the highest average review ratings?
- How do standard and express shipping orders compare?
- How do subscription groups compare by average spend and total revenue?
- Which products have the highest discount rates?
- How can customers be grouped by previous-purchase behaviour?
- Which products are most purchased within each category?
- How do repeat purchases relate to subscription status?
- How is revenue distributed across age groups?

## 🧰 Tools & Files

- **SQL** — queries and customer segmentation in `customer_behavior.sql`
- **CSV** — source data in `customer_shopping_behavior.csv`
- **Jupyter Notebook** — analysis in `customer_shopping_behavior_analytics.ipynb`
- **Power BI** — dashboard file in `project customer_behavior_Dashboard.pbix`

## 🚀 How to Explore

1. Clone the repository:
   ```bash
   git clone https://github.com/pushkarsingh88603-data/customer_shopping_behavior_analytics.git
   cd customer_shopping_behavior_analytics
   ```
2. Import `customer_shopping_behavior.csv` into your SQL database.
3. Update the database and table names in `customer_behavior.sql` to match your local setup. The current queries expect a database named `customer_behavior` and a table named `customer`.
4. Run the SQL queries in your database client.
5. Open the notebook in Jupyter to explore the notebook-based analysis.
6. Open the `.pbix` file with Power BI Desktop to inspect the dashboard.

## 📊 Analysis Approach

The SQL script uses aggregation, filtering, subqueries, common table expressions, conditional logic, and window functions to investigate shopping patterns.
